# Foxl Browser Extension 0.10.0

A clearer conversation, right beside the page. This release redesigns the side
panel and settings with Foxl's Geist typography, readable 16px message text, and
a rounded composer.

## What changed

- Ask follow-up questions with the recent conversation in context. New chat
  clears the panel's conversation.
- See which page accompanies your message. The Current page control follows
  the panel's own Chrome window and can exclude the page's title and URL.
- Edit a starting prompt before sending it. Shift+Enter adds a new line, and
  Enter during IME composition no longer sends unfinished text.
- Choose Light, Dark, or System appearance and check the actual Desktop
  connection from the redesigned settings page.
- Responses return to the panel that sent the request. Lost connections show
  an explicit error, and completed requests clear the page activity indicator.
- The README and store gallery now use real Light-mode captures from the
  running extension, including actual NASA page tasks and follow-up answers.

**Requires Foxl Desktop.** The extension connects to the app running on your
computer by default. Agent tasks use the model connection configured in Desktop.
With Desktop 0.9.3, side-panel answers appear when a task completes.

This release requests the same seven permissions as 0.9.0 and adds no runtime
dependencies. If updating from 0.8.x or earlier, review Chrome's permission prompt
for the background-capture capability introduced in 0.9.

## Files

- `foxl-browser-extension-0.10.0.zip` — the versioned extension package.
- `foxl-browser-extension-latest.zip` — identical bytes under the stable filename.
- `SHA256SUMS.txt` — SHA-256 digests for both ZIP names.

Extract the versioned ZIP into a directory, open `chrome://extensions`, enable
Developer mode, and choose Load unpacked to load that directory.

## Verify the package

Compute the ZIP's digest and compare it with the matching line in `SHA256SUMS.txt`:

```sh
shasum -a 256 foxl-browser-extension-0.10.0.zip
```

The package is byte-reproducible from the release source:

```sh
git checkout v0.10.0
node scripts/audit.mjs
node --test scripts/*.test.mjs
node scripts/build.mjs
shasum -a 256 dist/foxl-browser-extension-0.10.0.zip
```

The source review record is in `store/QUALITY.md`. Native capture provenance,
crop metadata, and the store image digests are kept with the source.
